# Doppelgone for Mac

Find and clean up duplicate photos in your Mac's Photos library and folders. The best shot stays; removed photos
can be restored for 30 days.

**Download:** [doppelgone.app/download](https://doppelgone.app/download)

This repository only holds the signed, notarised Mac downloads and the app's update feed. Each release has:

- `Doppelgone-arm64.dmg` for Apple silicon Macs (M1 and newer)
- `Doppelgone-x64.dmg` for Intel Macs
- the zips and `latest-mac.yml` the app uses to update itself

Requires macOS 14 (Sonoma) or newer. Support: support@doppelgone.app
